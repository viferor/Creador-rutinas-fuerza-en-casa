# 🇪 Español

## 🎯 ¿Qué es Cuidate !!?

**Cuidate !!** es una aplicación web de entrenamiento de fuerza diseñada para quienes quieren entrenar de forma inteligente, personalizada y sin complicaciones. Olvídate de apps llenas de anuncios, suscripciones de pago y registros interminables. Aquí todo es tuyo, desde el primer segundo.

### ✨ ¿Por qué Cuidate !!?

- 🆓 **100% gratuita para siempre** — Sin suscripciones, sin versiones "premium"
- 🚫 **Sin anuncios** — Tu experiencia limpia y sin distracciones
- 🔒 **100% privada** — Tus datos nunca salen de tu navegador
- ⚡ **Sin instalación** — Abre y entrena, así de simple
- 🌍 **Bilingüe** — Español e inglés con un solo clic
- 📱 **Responsive** — Funciona en móvil, tablet y escritorio

## 🚀 Características Principales

###  Generador Inteligente de Rutinas

Crea rutinas adaptadas a **tu realidad**, no a una plantilla genérica:

| Parámetro | Opciones |
|-----------|----------|
| 🎯 **Tipo de sesión** | Full Body · Tren Superior · Tren Inferior · Empuje · Tirón · Músculo específico |
|  **Nivel de experiencia** | 🌱 Principiante · 💪 Intermedio · 🔥 Avanzado · ⚡ Experto |
| 🏋️ **Estilo** | Todos · Solo peso corporal · Isométricos · Mixto |
| 🔢 **Volumen** | 2, 3 o 4 series por ejercicio |
| 🛠️ **Equipamiento** | 11 tipos: Mancuernas, Barra, Kettlebell, Polea, Máquina, Smith, Bandas, Fitball, Barra Z, Peso corporal y más |

> 💡 **Filtrado inteligente**: La app solo te propone ejercicios que puedes hacer con el material que tienes disponible. ¿Solo tienes tu cuerpo? Perfecto, te generará una rutina 100% bodyweight.

###  Base de Datos de 1.324 Ejercicios

- 🎬 **GIFs animados** de cada ejercicio (cortesía de Gym visual)
- 📝 **Instrucciones paso a paso** en español e inglés
- 🎯 **Músculo objetivo** y músculos secundarios
- 🏷️ **Clasificación por dificultad** automática (Principiante → Experto)
- ️ **Organizados por grupo muscular**: Pecho, Espalda, Hombros, Brazos, Piernas, Core, Cardio, Cuello

### 🔄 Control Total de tu Sesión

Una vez generada la rutina, tú mandas:

- ⬆️️ **Reordena** los ejercicios como quieras
- 🔄 **Sustituye** cualquier ejercicio por una alternativa del mismo grupo muscular
-  **Elimina** lo que no te convenza
- ✅ **Marca series completadas** en tiempo real
- ⌨️ **Registra kg y repeticiones** de cada serie
- 📝 **Añade notas** sobre sensaciones, molestias o PRs

### 📖 Biblioteca de Rutinas

-  **Guarda tus rutinas favoritas** con un nombre personalizado
- 🔗 **Compártelas por enlace** — envíalas por WhatsApp, email, lo que quieras
- 📤 **Exporta como archivo JSON** para backup o para usar en otro dispositivo
- 📥 **Importa rutinas** desde archivo o desde un enlace compartido
- 🗑️ **Gestiona tu biblioteca** — edita, comparte o elimina cuando quieras

### 📊 Historial y Estadísticas

Cada entrenamiento finalizado se guarda automáticamente:

- 📅 Fecha y hora
- 🏋️ Número de ejercicios
- ✅ Series completadas vs totales
- ⚖️ **Volumen total en kg** (series × kg × reps)
- 📝 Tus notas personales
- 🔍 **Vista detallada** de cada sesión con todos los ejercicios

###  Bilingüe Real

No es una traducción automática cutre. Cada texto, cada botón, cada mensaje está cuidadosamente traducido:

- 🇪🇸 **Español** completo
- 🇬 **Inglés** completo
- 🔄 Cambio instantáneo con un solo clic
-  Tu idioma preferido se guarda automáticamente

## 🛠️ Tecnologías

- **HTML5** + **CSS3** (variables CSS, Grid, Flexbox, animaciones)
- **JavaScript ES6+** (sin frameworks, sin dependencias)
- **Base de datos**: [exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset) (1.324 ejercicios, MIT)
- **CDN**: jsDelivr para carga rápida
- **Almacenamiento**: `localStorage` del navegador
